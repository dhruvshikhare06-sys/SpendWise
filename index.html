Your data stays in this browser

SpendWise uses localStorage. Clearing browser site data may remove your records, so use the backup feature regularly. This demo does not use a cloud account or server. Multiple currencies are stored separately; totals and charts are filtered by the selected reporting currency rather than converted using guessed exchange rates.
